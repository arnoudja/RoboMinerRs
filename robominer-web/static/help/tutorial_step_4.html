When you have enough ore, visit the shop. Buy an Enhanced Memory Module first (5 Cerbonium). It raises program memory from 4 to 8 so the next tutorial step can fit.

Select the part in the catalog and click Buy part.

Open the robots page, assign the new memory to your robot, and click Apply changes.

A bigger ore container can wait until after you can compile larger programs. Keep checking mining results to find other weak spots as you earn more ore.
